### A little about me

I'm a software developer in Missoula, Montana, focused on backend development with Go. I've worked with Go, C#, SQL databases, and React, and I enjoy connecting the pieces that make an application work.

I'm happiest digging into a bug, figuring out why something broke, and getting it working again. I care about code that's easy to follow, clear boundaries between parts of a system, and tests that catch real problems.
